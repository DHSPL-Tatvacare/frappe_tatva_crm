# tatva_frappe_crm

A modified version of [Frappe CRM](https://github.com/frappe/crm), customized for TatvaCare's internal purposes.

This repository contains source code derived from Frappe CRM with changes specific to TatvaCare's workflows. It is not the upstream project and is maintained independently.
